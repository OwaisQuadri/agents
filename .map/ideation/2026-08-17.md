# Pi and Herdr working environment

## Current state

The tool manifest installs pinned commands and Pi extensions on macOS and Linux. Pi already loads the repository's retrieval extension. Herdr can create worktrees, tabs, panes, and run commands, but no repository-owned setup creates the requested workspace. The engineering map already has human gates, but it does not use Wayfinder, grilling, `show-me`, or Plannotator.

## Make it work

### Pilot the pinned Pi package stack with external telemetry

Install `nicobailon/pi-subagents`, Plannotator, and the `show-me` skill from pinned upstream revisions. Keep each upstream checkout unchanged. Record package version, invocation, duration, result status, human correction, and cost data that Pi exposes. Do not record prompt or file contents by default. This depends on AGNT-0008.

### Run Claude Code as a subscription-backed Pi child

Define a project-owned Pi agent that invokes the installed `claude` command through the external command runner in `nicobailon/pi-subagents`. Verify the local Claude Code flags instead of copying the package example. Run one child task and confirm that it appears in Claude subscription usage before making this route the default. This depends on the Pi package pilot.

### Create the Herdr worktree setup

Install `herdr-fresh-worktree` from a pinned revision. Add one idempotent Herdr setup that creates two tabs for a new or opened worktree. Tab one contains Pi at 75 percent width and a shell at 25 percent. Tab two contains Neovim at 75 percent and a shell at 25 percent. Define ownership and ordering between the fresh-worktree handler and `hooks/post-checkout` before either changes a new worktree. This depends on AGNT-0008.

### Show live request and overall diffs in Pi

Add one repository-owned Pi extension. Capture an immutable Git tree when a user request starts. Refresh the request diff and the overall worktree diff after write-capable tool calls and when the agent settles. Include staged, unstaged, untracked, renamed, and binary files without changing the worktree or index. Provide compact live status plus commands for the full request and overall views. This depends on AGNT-0008.

### Add decision aids to the engineering gates

Add Wayfinder's destination, frontier, fog, and out-of-scope fields to planning. Use grilling only where unresolved answers can change execution. Use `show-me` for concise system views and Plannotator for visual plan or diff feedback. Keep the existing human gates as the authority. This depends on the Pi package pilot.

## Make it right

### Normalize the existing agents for Pi discovery

Add a derived Pi adapter for the repository's agent definitions. Convert tool names and provider-specific model aliases without creating a second prompt source. Disable overlapping bundled agents only after the repository roles pass one representative run through Pi. This depends on the Pi package pilot.

### Define a fork threshold from telemetry

Keep upstream packages pinned and unchanged until three reproduced failures share one source-level cause. Configuration, wrappers, or project-owned agents must fail to fix that cause. Record the evidence and the upstream response before creating a fork. This depends on external telemetry.

## Make it fast

No performance ticket yet. First measure child startup time, package load time, diff refresh cost, and Herdr setup time. File an optimization only after a measured delay crosses a human-visible interaction boundary.

## Innovation

### Make the worktree a replayable cockpit

Store a repository-owned recipe that rebuilds the Herdr tabs, active commands, selected ticket, current gate, live diff state, and child-agent fleet view. Restore it after a restart. The recipe would replace separate setup scripts with one inspectable workspace state. This depends on the Herdr setup, Pi telemetry, and live diff extension.

## Research

The package shortlist reuses the source review completed before this ideation pass. `nicobailon/pi-subagents` supplies external command runners and Herdr observability. Plannotator supplies visual plan and diff annotation. HumanLayer's `show-me` supplies concise visual artifacts.

`herdr-fresh-worktree` updates only safe new worktrees. Wayfinder and grilling supply planning and dependency-ordered questions. The other reviewed goal-loop, workflow, reviewer, and duplicate subagent packages overlap the existing engineering map.
