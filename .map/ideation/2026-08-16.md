# Tool distribution across agent harnesses

## Current state

`mcp-sync` already renders one Model Context Protocol server manifest into Claude Code and Codex. The installer already shares skills and instructions between those two harnesses. The next work must add acquisition, installation, shell commands, Pi support, and native platform handling without replacing machine-local settings.

## Make it work

### AGNT-0008: Install local and remote tools from one manifest

Define one tracked manifest for an embedded tool or a Git source. Record its pinned revision, supported operating systems, install command, provided commands, and harness adapters.

Add a Rust sync tool that fetches remote repositories into one managed cache. It must refuse dirty updates, run the declared installer, link commands, and report skipped platforms. Replace the current Pi draft with supported Pi extension and skill paths. Use `OwaisQuadri/rag` as the first macOS and Linux proof. Depends on no open ticket.

### AGNT-0009: Install shell and Secure Shell aliases from the tool manifest

Render managed Bash, Z shell, and PowerShell command files from the same manifest. Add `cld` for `claude --dangerously-skip-permissions`. Render a managed Secure Shell include for the `archlinux` Tailscale host without replacing the user's main Secure Shell config. Depends on AGNT-0008.

### AGNT-0010: Redirect agent edits from generated configs to the source manifest

Install guards for Claude Code, Codex, and Pi. They must block direct agent writes to managed configuration fields. Each refusal must name the tracked source file or adopt command. Keep human edits and unmanaged configuration fields intact. Depends on AGNT-0008.

### AGNT-0011: Run the installer on native Windows

Move platform and manifest work into the Rust sync tool. Keep the shell installer as an orchestrator for macOS and Linux. Add a PowerShell entry point for Windows. Test destination paths and skip reasons on all three operating systems. Depends on AGNT-0008, AGNT-0009, and AGNT-0010.

## Make it right

AGNT-0008 must keep `config/mcp-servers.toml` as the Model Context Protocol server source and reference it from the tool manifest. It must not create a second server definition that can drift.

## Make it fast

No performance ticket yet. Correct dry runs, safe updates, and repeatable installs come before fetch caching beyond the normal Git object cache.

## Innovation

No innovation ticket yet. The requested local and remote source model already removes the current manual work. A package registry or signed catalog needs an observed distribution problem first.
