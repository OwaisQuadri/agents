# Pi configuration follow-ups

Source: AGNT-0088 manual sign-off, 2026-08-26.

## Dependency frontier

AGNT-0088 delivered the owned Pi footer, local dictation, managed configuration,
and the fleet display changes. The closeout audit found one stale `stt.json` link
from the replaced custom voice system. The installer now retires it.

## Make it work

### User vocabulary replacements for local dictation

Let the user maintain a small replacement map that changes recurring names and
terms after local transcription. This restores the custom-word need from the
original dictation choice without changing the local transcription engine.

Dependencies: pi-transcribe configuration surface and its post-transcription
text path must be probed first.

## Make it right

### Reconcile retired Pi resources during installation

Turn the one-off `stt.json` retirement into a manifest-owned list of superseded
Pi resources. The installer verifies that each retired path is absent or safely
moved before it reports success.

Dependencies: none. This must land before performance work.

## Make it fast

### Measure local dictation first-use and steady-state latency

Measure model download, first transcription, and later transcription on the
current Mac. Report the times before any caching or preload work is proposed.

Dependencies: the retired-resource reconciliation ticket.

## Innovation

### Build a read-only Pi configuration doctor

Compare the managed manifest with the live Pi configuration and report dangling
links, unmanaged regular files in managed roots, retired resources, and package
revision drift. It proposes the exact installer action but changes nothing.

Dependencies: retired-resource reconciliation defines the owned and retired
resource inventory. No new runtime dependency.
