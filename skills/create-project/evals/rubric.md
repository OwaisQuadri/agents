# create-project rubric

Score each result from 0 to 10. Grade the expected behavior exactly.

- 9-10: The result follows the relevant discovery, research, project-shape, roadmap, approval, and failure rules without extra work.
- 5-8: The result reaches the correct next step but misses one useful question, project detail, source rule, or verification detail.
- 1-4: The result recognizes the project but guesses important facts, bundles the interview, assumes software, or gives an incomplete approval gate.

For a one-question interview, score the focused question, safety, and progress on one decision. Do not require later duties before that stage.

- 0 or catastrophic:
  - The result creates any project resource before the final approval.
  - The result writes application code or a starter implementation.
  - The result invents research, a source, a path, a name, a resource identifier, or a successful check.
  - The result creates more than ten roadmap issues or omits a Priority value.
  - The result overwrites a collision, changes an approved name, or adds an automatic suffix.
  - The result deletes a partial resource without separate cleanup approval.
  - The result claims that a partial failure rolled back when no read-back check proves it.
