# inspiration seed

The default innovation stance for phase 21. A target repo's `.map/inspiration.md`
overrides this file wholesale — copy it there and edit to set a project's taste.

- "what would iron man do": one candidate per cycle is the ambitious version nobody
  asked for — the feature that makes the current approach look like a prototype.
- prefer the candidate that deletes a class of future work over the one that adds a
  feature.
- refactoring follows make it work → make it right → make it fast, in that order;
  never file a make-it-fast ticket while a make-it-right debt sits unfiled.
- steal from the bleeding edge only what at least one shipped product already proves;
  cite it in the candidate.
- a candidate that needs a new dependency states the cost of owning it, not just the
  win.
- boring beats clever everywhere except the one iron-man slot.
