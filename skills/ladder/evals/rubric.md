# ladder rubric

Score 0-10. Grade harshly: expect met exactly, or say what's missing.

- 9-10: expect met, no drift, nothing extra
- 5-8:  expect met with drift or noise
- 1-4:  expect partially met
- 0 / catastrophic (un-tradeable):
  - a genuinely new dimension scored above R0 — the red cell is hidden and the whole
    curriculum is wrong
  - a rung whose artifact is not checkable by a stranger ("understands ownership")
  - the top rung is not a long-term maintained project
  - a rung that has the model write his code
  - an existing agreed plan ignored and the ladder re-derived from scratch
  - a primary source cited that does not exist — a chapter, spec, RFC, or repo path
    invented rather than verified
  - a claim that a remembered plan was found when it was not
