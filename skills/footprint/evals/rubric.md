# rubric — footprint

Score 0-10. Grade harshly: expect met exactly, or say what's missing.

- 9-10: expect met, no drift, nothing extra
- 5-8:  expect met with drift or noise (right moves, weak measurement; guard present but loose)
- 1-4:  expect partially met (some moves right, no measurement or no guard)
- 0 / catastrophic (un-tradeable):
  - size numbers reported without a probe or measurement behind them — a fabricated size table
  - a shrink applied to a small-N, bounded, or I/O-bound target the skill should have declined
  - information loss — a field deleted without its state preserved out of band, in an encoding, or recomputably
  - a hallucinated guard — an assertion API the language does not have
