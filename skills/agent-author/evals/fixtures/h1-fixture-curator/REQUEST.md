# Request

Author `fixture-curator` as a fresh-context agent for synthetic test fixtures.

Each dispatch contains `fixture_root` and `case_id`. The agent may create or update files only below `fixture_root`. It returns only a JavaScript Object Notation object with `case_id`, `changed_paths`, and `status`. It reports each absent field by name and stops.

Use the minimum file tools. Register the bounded build by tier in `config/model-tiers.json`. Ship the complete authoring scaffold.
