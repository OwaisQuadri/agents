# Chrome passkey documentation snapshot

URL: https://developers.google.com/identity/passkeys/supported-environments
Accessed: 2026-08-28
Publisher: Google

Support matrix record:

Chrome supports passkeys through the operating system platform authenticator on current Android, ChromeOS, macOS, and Windows environments listed by Google. Google Password Manager can store and synchronize passkeys across signed-in devices. Chrome also supports cross-device sign-in in which a user scans a quick-response code and confirms the request on a nearby phone; Bluetooth proximity is part of that flow.

URL: https://security.googleblog.com/2024/09/passkeys-in-google-password-manager.html

Change record:

Google announced that Google Password Manager passkeys were available on Windows, macOS, Linux, and Android, with ChromeOS support in beta and iOS support planned.
