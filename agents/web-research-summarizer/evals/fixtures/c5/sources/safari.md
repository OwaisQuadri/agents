# Safari passkey documentation snapshot

URL: https://support.apple.com/guide/iphone/use-passkeys-and-passwords-iphf538ea8d0/ios
Accessed: 2026-08-28
Publisher: Apple

Support record:

Apple documents passkeys as a replacement for passwords that use Face ID or Touch ID for approval. Passkeys saved in Passwords and iCloud Keychain are available on approved Apple devices signed in to the same Apple Account. Apple also documents using a passkey on another device by scanning a quick-response code and approving with the device that holds the passkey.

URL: https://developer.apple.com/passkeys/

Platform record:

Apple's passkey overview identifies iCloud Keychain as the synchronization mechanism and lists Safari on Apple platforms as a passkey client. The snapshot contains no dated Safari release-note entry from the preceding year.
