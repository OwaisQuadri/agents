# Firefox passkey documentation snapshot

URL: https://support.mozilla.org/en-US/kb/passkeys-firefox
Accessed: 2026-08-28
Publisher: Mozilla

Support record:

Mozilla documents passkey use in Firefox through supported device and operating-system authenticators. The support page distinguishes using a passkey from storing and synchronizing one. Firefox can invoke the platform account or password manager exposed by the operating system; the page does not state that Firefox Sync stores passkeys.

URL: https://www.mozilla.org/en-US/firefox/122.0/releasenotes/
Published: 2024-01-23
Publisher: Mozilla

Change record:

Firefox 122 release notes state that passkeys stored in the iCloud Keychain on macOS are supported. The offline packet contains no newer Firefox release note.
