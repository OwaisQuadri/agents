# Anthropic rate-limits documentation snapshot

URL: https://docs.anthropic.com/en/api/rate-limits
Accessed: 2026-08-28
Publisher: Anthropic
Scope: first-party Claude API

Extracted documentation:

Rate limits apply at the organization level. The documented measurements include requests per minute, input tokens per minute, and output tokens per minute. Limits depend on usage tier and model. The response headers expose the active request and token limits, remaining capacity, and reset times.

The public page describes tier advancement and the limit dimensions. It does not publish one universal Opus, Sonnet, or Haiku request rate that applies to every organization. Customers must use the Limits page in Claude Console for the numeric limits active for their organization.
