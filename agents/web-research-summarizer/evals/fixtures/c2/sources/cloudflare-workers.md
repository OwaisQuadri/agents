# Cloudflare Workers documentation snapshot

URL: https://developers.cloudflare.com/workers/platform/pricing/
Accessed: 2026-08-28
Publisher: Cloudflare

Pricing record:

Workers Free includes a daily request allowance. Workers Paid uses a monthly subscription with included requests and central processing unit time, then usage charges above the included amounts. Duration is not billed while a Worker waits on network input/output.

URL: https://developers.cloudflare.com/workers/platform/limits/
Accessed: 2026-08-28
Publisher: Cloudflare

Outbound-request record:

The limits page calls outbound fetches, redirects, and service bindings subrequests. It documents 50 subrequests per invocation on Free and 1,000 per invocation on Paid.

Startup record:

Cloudflare describes isolates that can start in under five milliseconds and a deployment technique that starts an isolate during the network connection setup. This provider post is older than the requested 12-month recency window.
